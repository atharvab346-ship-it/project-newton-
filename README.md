# Project Newton

An interactive projectile motion simulator. Enter a launch speed, angle and
gravity, and it shows the horizontal range, maximum height and time of flight,
along with an animated path.

**Live site:** https://yourname.github.io/project-newton

## Features
- Sliders and number boxes for speed, angle and gravity
- Gravity presets for Earth, Moon, Mars and Jupiter
- Animated path with a time slider to move through the flight
- Keep several paths on screen to compare angles
- Working shown with your numbers substituted into the formulas

## Formulas used
- Range: R = u² sin 2θ / g
- Maximum height: H = (u sin θ)² / 2g
- Time of flight: T = 2u sin θ / g

These assume the object lands at its launch height and ignore air resistance.

## Built with
HTML, CSS and JavaScript. A Java console version of the calculator is also
included in this project.
